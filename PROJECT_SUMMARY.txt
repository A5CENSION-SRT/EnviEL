📊 PROJECT OVERVIEW
════════════════════════════════════════════════════════════════════════════════

A native Android audio player app that connects to your EnviEL web dashboard to 
display real-time gunshot (🔫) and animal (🦁) detection audio playback.

Perfect for field demonstration of the anti-poaching detection system.

🚀 QUICK START
════════════════════════════════════════════════════════════════════════════════

1. Generate Audio Files:
   $ node scripts/generate-audio-samples.js
   
2. Start Web Server:
   $ npm run dev
   
3. Build & Deploy Android App:
   $ cd android
   $ ./gradlew installDebug
   
4. Configure Mobile App:
   - Tap ⚙️ Settings
   - Enter: http://YOUR_IP:3000
   - Tap Save
   
5. Test It:
   - Open mobile app
   - Select Gunshot category
   - Play first audio file
   - Check dashboard for real-time event ✅


💡 HOW IT WORKS
════════════════════════════════════════════════════════════════════════════════

ONLINE MODE:
  Mobile: Play audio
    ↓
  Mobile: POST /api/audio-events
    ↓
  Server: Store event in memory + database
    ↓
  Dashboard: GET /api/audio-events every 10s
    ↓
  Dashboard: Display in real-time section

OFFLINE MODE:
  Mobile: Detect no network
    ↓
  Mobile: Show "📡 OFFLINE MODE" banner
    ↓
  Mobile: Play local mock audio files
    ↓
  Mobile: Queue events in memory
    ↓
  Mobile: Reconnect to network
    ↓
  Mobile: Sync queued events to server

🐛 TROUBLESHOOTING REFERENCE
════════════════════════════════════════════════════════════════════════════════

Mobile Can't Connect:
  → Check server IP in Settings ⚙️
  → Verify both on same WiFi
  → Confirm npm run dev is running

Dashboard Doesn't Update:
  → Play audio on mobile first
  → Refresh browser page
  → Check browser DevTools console

Audio Files Not Found:
  → Run: node scripts/generate-audio-samples.js
  → Verify files in public/audio/

Build Fails:
  → Android: See android/README.md
  → Web: Try npm install && npm run build

See MOBILE_INTEGRATION.md for comprehensive troubleshooting
