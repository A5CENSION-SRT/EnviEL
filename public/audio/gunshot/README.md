# Gunshot Detection Audio Files

Sample gunshot detection recordings for demonstration purposes.

## Files

- `detection_001.wav` - Gunshot detection sample 1 (3.5s)
- `detection_002.wav` - Gunshot detection sample 2 (2.8s)
- `detection_003.wav` - Gunshot detection sample 3 (4.1s)
- `detection_004.wav` - Gunshot detection sample 4 (3.2s)
- `detection_005.wav` - Gunshot detection sample 5 (3.8s)

## Format

- Format: WAV (PCM 16-bit, 44.1kHz)
- Channels: Mono
- These are synthetic tones for demonstration (not actual gunshot audio)

## Usage

These files are served via `/api/audio-files?type=gunshot` and can be played in the mobile app.
