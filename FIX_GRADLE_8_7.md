# Upgrade to Gradle 8.7

I've updated the Gradle configuration. Follow these steps:

## In Android Studio:

1. **File → Sync Now**
   - Android Studio will download Gradle 8.7
   - Takes 1-2 minutes first time

2. **Wait for "Gradle sync completed successfully"**

3. **Build → Rebuild Project**

4. **Click green ▶️ Run button**
   - Select device
   - App builds and installs ✅

---

## What Changed:

✅ Gradle: 8.5 → **8.7**
✅ Android Gradle Plugin: 8.5.0 → **8.7.0**
✅ Kotlin: 1.9.20 → **1.9.23**

All compatible now!
