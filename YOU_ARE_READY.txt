QUICK START (6 STEPS):

  1. Enable phone hotspot
     Settings → Hotspot & Tethering → Turn ON
     
  2. Connect laptop to hotspot
     WiFi settings → Select phone network → Connect
     
  3. Find laptop IP
     Open CMD: ipconfig | grep IPv4
     Note this IP (e.g., 192.168.43.100)
     
  4. Start dashboard
     cd c:\coding\EnviEL
     npm run dev
     
  5. Configure VLC app
     Phone → Open VLC → Tap ⚙️ Settings
     Enter: http://192.168.43.100:3000 (use your IP)
     Tap Save
     
  6. Test it
     VLC: Tap 🔫 GUNSHOT → Play audio
     Laptop: Check dashboard → Should show event! ✅
