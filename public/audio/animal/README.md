# Animal Detection Audio Files

Sample animal distress detection recordings for demonstration purposes.

## Files

- `detection_001.wav` - Animal detection sample 1 (5.2s)
- `detection_002.wav` - Animal detection sample 2 (4.6s)
- `detection_003.wav` - Animal detection sample 3 (6.1s)
- `detection_004.wav` - Animal detection sample 4 (4.9s)
- `detection_005.wav` - Animal detection sample 5 (5.4s)

## Format

- Format: WAV (PCM 16-bit, 44.1kHz)
- Channels: Mono
- These are synthetic tones for demonstration (not actual animal audio)

## Usage

These files are served via `/api/audio-files?type=animal` and can be played in the mobile app.
